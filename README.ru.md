# X-Boost — сайт агентства вертикальных видео

[English](README.md) | **Русский**

Маркетинговый сайт **X-Boost** — агентства, которое делает для бизнеса короткие вертикальные видео (Reels, TikTok, Shorts). На сайте представлены услуги агентства, кейсы клиентов и форматы видео, а встроенный калькулятор помогает оценить эффект от видеокампании.

Проект начался как переписывание оригинального сайта агентства с React на **Next.js (App Router)**. Сайт работает на трёх языках (английском, русском и украинском), и большая часть контента на нём — видео.

## Возможности

- **Три языка** с префиксом локали в адресе (`/en`, `/ru`, `/uk`) на `next-intl`. Все тексты, ссылки и пути к медиа хранятся в файлах переводов, поэтому для изменения контента не нужно трогать компоненты.
- **Главная страница**: первый экран, результаты в цифрах, кейсы клиентов с видео, как устроена работа и список категорий видео.
- **Страницы категорий** (`/category/faceless`, `/talkingHead`, `/socialSurvey`, `/thirdPerson`). У каждой свой первый экран, карусель форматов видео с хештегами и ссылки на другие категории. Несуществующая категория отдаёт 404.
- **Калькулятор кампании**: форма с валидацией на Zod (подписчики, просмотры, бюджет, категория, платформы). Считает охват, прирост подписчиков, количество видео и экономию, а числа форматирует под язык страницы.
- **Статическая генерация**: все страницы для всех языков и категорий собираются заранее, при сборке.
- **SEO**: свои title и description на каждом языке, canonical-ссылки и `hreflang`.
- **Быстрая загрузка видео**: видео подключается, только когда появляется на экране (IntersectionObserver), а до загрузки показывается скелетон.
- **Согласие на cookies**: Google Analytics подключается только после того, как посетитель согласился.
- **Адаптивная вёрстка**: выпадающее меню на десктопе, боковое меню на мобильных и навигация, которая прячется при прокрутке.

## Стек

| Область | Инструменты |
| --- | --- |
| Фреймворк | Next.js 14 (App Router), React 18 |
| Язык | TypeScript и JavaScript (постепенный переход на TypeScript) |
| Локализация | next-intl (middleware для локалей, общие хелперы навигации) |
| Стили | Tailwind CSS, своя палитра бренда и утилиты фоновых паттернов |
| UI-примитивы | Radix UI (компоненты в стиле shadcn/ui), class-variance-authority, lucide / react-icons |
| Формы | react-hook-form + Zod |
| Анимация и карусели | Framer Motion, Embla Carousel |
| Тесты | Vitest (формулы калькулятора) |
| Аналитика | Google Analytics, после согласия на cookies |
| Инструменты | ESLint (next/core-web-vitals), Prettier с плагином для Tailwind |

## Структура проекта

```
app/[locale]/                      layout'ы и страницы, одно дерево маршрутов на локаль
  (public)/page                    главная страница
  (public)/category/[slug]/page    страницы категорий
app/navigation                     список локалей и Link / router с учётом локали
middleware                         маршрутизация локалей next-intl
components/
  ui/                              переиспользуемые примитивы (кнопки, заголовки, карусель, загрузчик видео, формы…)
  page/main-page/                  секции главной страницы
  page/categories-page/            секции страниц категорий, включая калькулятор
  page/shared/                     шапка, футер, баннер cookies
lib/                               категории, SEO-хелперы, настройка i18n, утилиты
messages/{en,ru,uk}.json           весь контент сайта: тексты, ссылки, пути к видео
public/video, public/imgs          медиафайлы
```

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:3000 (перенаправляет на /en)
npm run build      # production-сборка
npm test           # юнит-тесты
npm run lint
```

Необязательные переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_GOOGLE_ANALYTICS` | ID потока Google Analytics. Если не задан, аналитика отключена |
| `NEXT_PUBLIC_SITE_URL` | Базовый адрес для canonical и `hreflang` (по умолчанию `https://xboosthub.com`) |
